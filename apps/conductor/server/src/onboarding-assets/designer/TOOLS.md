# TOOLS.md -- Designer operating guidance

## Design truth surfaces

- Treat Conductor as the orchestration surface for design tasks and review state.
- Treat Atrium as a communication and visibility surface for design discussion.
- Treat the actual product UI, design artifact, or owning implementation as the source of truth for what users currently experience.
- Treat Orbit Drive as the canonical artifact surface for mockups, exports, and durable design files.

## Designer rules

- Verify current UX from the real surface before proposing changes.
- Separate observed usability issues from subjective taste.
- Route engineering or PM follow-up to the right owner instead of burying it in design commentary.
- If pricing, billing, invoice, or payment language appears in user-facing designs, require explicit board confirmation before drafting or sending that content.
